# HDKALA | فروشگاه اینترنتی

فروشگاه اینترنتی ایرانی با **React + TypeScript + Tailwind CSS + jQuery** — تک‌صفحه‌ای (SPA)، راست‌به‌چپ و فارسی، با پنل مدیریت کامل.

---

## راه‌اندازی (فقط یک راه!)

دیگر چند پروژه و چند حالت متفاوت وجود ندارد؛ کل پروژه **یک اپلیکیشن واحد** است:

```bash
npm install     # نصب وابستگی‌ها (فقط بار اول)
npm run dev     # اجرای حالت توسعه  →  http://localhost:5173
```

خروجی آماده انتشار:

```bash
npm run build    # typecheck + ساخت نسخه نهایی در پوشه dist/
npm run preview  # پیش‌نمایش نسخه ساخته‌شده  →  http://localhost:4173
```

> چرا حالا همه‌جا یکسان دیده می‌شود؟
> قبلاً دو پروژه جدا (`store/` با HTML خام و `react-app/` با React) وجود داشت که با Live Server
> و `npm run dev` دو چیز متفاوت باز می‌شد. حالا فقط **یک پروژه** هست و مسیریابی آن
> **HashRouter** است؛ یعنی خروجی `npm run build` حتی با باز کردن مستقیم یا Live Server
> هم دقیقاً همان چیزی را نشان می‌دهد که در حالت توسعه می‌بینید.

## تکنولوژی‌ها

| ابزار | کاربرد |
| --- | --- |
| React 18 + TypeScript | رابط کاربری (همه کدها با تایپ امن) |
| Vite | بیلد و سرور توسعه |
| Tailwind CSS | استایل‌دهی |
| React Router (HashRouter) | مسیریابی |
| Zustand | مدیریت state سراسری (با ذخیره در localStorage) |
| React Hook Form | فرم‌ها و اعتبارسنجی |
| jQuery | افکت محوشدن صفحه خوش‌آمد اولیه (در `main.tsx`) |

هیچ وابستگی اضافه‌ای نصب نمی‌شود؛ Playwright, تست e2e و ابزارهای غیرضروری حذف شده‌اند.

## ساختار پروژه

```
HDKALA/
├── index.html            # نقطه ورود + صفحه خوش‌آمد (jQuery آن را محو می‌کند)
├── package.json          # اسکریپت‌ها و وابستگی‌ها
├── vite.config.ts        # تنظیمات Vite
├── tsconfig.json         # تنظیمات TypeScript
├── tailwind.config.js    # تنظیمات Tailwind
├── postcss.config.js     # تنظیمات PostCSS
├── public/               # فونت‌ها، تصاویر و آیکون (دست‌نخورده کپی می‌شوند)
└── src/
    ├── main.tsx          # راه‌اندازی React + تم + jQuery splash
    ├── App.tsx           # تعریف همه مسیرها (فروشگاه + ادمین)
    ├── index.css         # Tailwind + فونت وزیرمتن + کلاس‌های مشترک
    ├── types.ts          # همه Typeها و ثابت‌های دامنه
    ├── data.ts           # داده‌ها: دسته‌بندی، محصولات اولیه، استان‌ها، روش‌های ارسال/پرداخت
    ├── utils.ts          # توابع کمکی: اعداد فارسی، قیمت، جمع سبد، اعتبارسنجی
    ├── store.ts          # استور Zustand (سبد، سفارش، کاربر، محصول، کوپن، تم…) + لایه API
    ├── components.tsx    # همه کامپوننت‌های مشترک (هدر، فوتر، کارت محصول، کشو، آیکون‌ها…)
    ├── pages.tsx         # همه صفحات فروشگاه (خانه، محصولات، سبد، تسویه، پروفایل…)
    └── admin.tsx         # پنل مدیریت (داشبورد، محصولات، سفارش‌ها، کاربران، نظرات، کوپن‌ها)
```

## قابلیت‌ها

- **فروشگاه:** صفحه اصلی، فیلتر/جستجو/مرتب‌سازی محصولات، صفحه جزئیات، سبد خرید، تسویه حساب چندمرحله‌ای، کد تخفیف، علاقه‌مندی‌ها، ثبت دیدگاه، پروفایل و پیگیری سفارش، حالت تاریک/روشن.
- **پنل مدیریت:** داشبورد با نمودار فروش ۷ روز، مدیریت محصولات (افزودن/ویرایش/حذف)، تغییر وضعیت سفارش‌ها، فعال/غیرفعال‌کردن کاربران، تأیید دیدگاه‌ها، ساخت کوپن تخفیف و تنظیمات فروشگاه (هزینه ارسال، آستانه ارسال رایگان…). داده‌های ادمین و فروشگاه از یک استور مشترک می‌آیند؛ هر تغییری در ادمین بلافاصله در فروشگاه دیده می‌شود.

## حساب‌های دمو

| بخش | مشخصات |
| --- | --- |
| پنل مدیریت (`/#/admin`) | نام کاربری `admin` — رمز `admin1234` |
| کاربر فروشگاه | دکمه «ورود سریع با حساب دمو» در صفحه ورود |
| کودهای تخفیف | `WELCOME10` (۱۰٪) و `SAVE50K` (۵۰ هزار تومان، سفارش بالای ۲۰۰ هزار) |

## نکات

- همه داده‌ها سمت مرورگر و در `localStorage` نگه‌داری می‌شوند (بک‌اند واقعی وجود ندارد). برای بازنشانی کامل، `localStorage` را پاک کنید.
- خطای تایپ‌ها را با `npm run typecheck` بررسی کنید.
